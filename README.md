# Day 1: ESP32 Blink

This project blinks the ESP32’s built-in LED, turning it on and off at one-second intervals.

## Hardware

- ESP32 DevKit v1

No external components are required.

## Wokwi Simulation

[Run the Day 1 blink simulation](https://wokwi.com/projects/476322923839444993)

## How to use

1. Start the Wokwi simulation.
2. Watch the built-in LED blink once per second.
